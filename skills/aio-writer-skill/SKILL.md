# 🤖 AIO Writer Skill (AI検索最適化執筆スキル)

このスキルは、従来のSEO（検索キーワード詰め込み）を超えて、**「AI検索（Perplexity, SearchGPT, Google Gemini等）が最も要約・引用しやすい構造化コンテンツ」** を生成するためのプロトコルです。

---

## 1. AIO（AI検索最適化）の設計原則

### ① 冒頭0フレームでの結論提示 (Direct Answer First)
AI検索のクローラーは「端的な回答」を最優先で探索する。
- 記事冒頭や各見出し（H2）の直後には、ポエムや長い導入を書かず、**最初の1〜2文で質問に対する直接の答え（結論）を定義**する。

### ② 比較・対比の表組み化 (Structured Tables & Lists)
AIが知識グラフとして抽出しやすいよう、比較対象がある場合はテキストの羅列ではなく **必ずMarkdownテーブル（表）または箇条書き** で対比する。

### ③ 定義ブロックの明確化 (Definition & Summary Boxes)
専門用語や重要な概念には、「要するに何か（TL;DR）」を1ブロックでまとめた要約枠（Quote/Box）を設置する。

---

## 2. 記事構成テンプレート（AIO Format）

```markdown
# [タイトル：読者の問いに答える明確な形式]

> **要約（TL;DR）**: 〇〇とは、△△によって□□を実現する仕組みです。

## 1. 結論：〇〇の核心
（冒頭1行で直接の回答を提示）

## 2. 比較表：従来手法との決定的な違い
| 項目 | 従来手法 | 本手法 |
| :--- | :--- | :--- |
| ... | ... | ... |

## 3. 実践手順（3ステップ）
1. ステップ1: ...
2. ステップ2: ...
3. ステップ3: ...
```
